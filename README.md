# HallSpan 考场间距排座

在考室网格上按最小曼哈顿距离排座，同试卷套不得四邻相邻，并输出违规与统计。

试卷套支持人数上下限：

- **上限**：同一试卷套的已座人数上限；某套触顶后即使考场仍有空位也不再塞入该套，未排原因仅记「同卷人数已满」。上限为 0 表示不截断。
- **下限（主卷保底）**：仅主卷套生效；排完后若主卷套已座人数低于下限，整场排座失败（HTTP 422，仅提示「主卷人数不足」），不生成/保存任何方案，也不以辅卷顶满格子充数。下限为 0 表示关闭保底。
- 上下限不可为负（负值拒绝保存，名册/排座图/统计三处均不变）。修改上下限后旧排座图立即作废，再排按新值出图。
- 名单各套人数、排座图套卷分布、统计页未排数同源于一份排座方案，恒等关系：名册人数 = 已座 + 未排。

技术栈：Python 3.12 / FastAPI / SQLAlchemy / PostgreSQL / Vue 3 / TypeScript / Vite

## 启动

```bash
docker compose up --build
```

| 服务 | 地址 |
| --- | --- |
| 前端 | http://localhost:4900 |
| API | http://localhost:9900 |
| API 文档 | http://localhost:9900/docs |
| Postgres | localhost:5450 |

健康检查：`GET http://localhost:9900/api/health`

## 使用说明

1. 在「考室」「考生」「试卷套」确认基础数据。
2. 打开「排座图」执行间距排座。
3. 在「违规」查看间距或同卷相邻问题。
4. 在「统计」查看占用与违规汇总。
